# Interview rubrics

One file per PM question type. Each has a one-line summary, a framework, what interviewers score,
and the common traps. The sensei uses them to set reps (`/kata`), run mocks (`/spar`), and grade
answers. Read the file for a question type before a rep, answer cold, then debrief against
"what they're scoring" and the traps.
