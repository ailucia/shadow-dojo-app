# my/

Everything about you lives here, and git never uploads it. Only this README is part of the
repo.

What ends up here:
- `shadow-dojo.json`: your save. Pick this folder when the app asks where to save.
- `sensei-context.md`: the sensei's notes on you, created by `/initiate`.
- `open-items.md`: things waiting on you, kept by `/kata`.
- `notion.md`: links to your Mission Layer databases in Notion.
- `resume/`: your resume masters and the plans `/forge` writes.
- `interviews/`: prep notes for each company you're interviewing with.
- `patterns/`: what a skill has learned about you, such as which referral notes got replies.
